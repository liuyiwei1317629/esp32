## 1. 背景

这是一个本地语音陪伴项目。云端 LLM 负责人格对话，本地只做功能命令。C 包负责把用户的一句话解析成**结构化命令**，不执行、不合成语音、不联网。

当前 bridge 只有 `POST /turn` 和 `POST /stop` 两个端点。`/stop` 是全局打断；`/turn` 是一问一答。规则命令由集成会话决定怎么执行。

## 4. 必须实现的 API

模块 `commands.py` 至少提供：

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class Command:
    kind: str                 # "stop" | "time" | "timer"
    seconds: int | None = None
    label: str = ""
    raw: str = ""


def parse_command(text: str) -> Command | None:
    ...
```

- `parse_command` 只做解析；不执行命令、不起线程、不 sleep、不调用 TTS/bridge。
- 无法识别时返回 `None`，不要返回 `kind="unknown"`。
- `raw` 保留用户原文（`strip()` 后），便于日志；不要放密钥。

## 5. 解析规则

### 5.1 归一化

- 用 `unicodedata.normalize("NFKC", text)` 把全角数字/标点转成常规形式。
- 去掉首尾空白。
- 匹配前去掉末尾的标点：`。！？!?~～…，,、` 和空白。
- 不要删除句子中间的标点；不要改变中文语义。
- 大小写不敏感只影响英文；中文不做拼音/模糊匹配。

### 5.2 `stop`：停止/打断

只有**整句**是下列短语之一（允许末尾语气词 `吧/啊/呀/呢/好吗/行吗` 和标点）才返回 `kind="stop"`：

```
停
停停
停一下
停一停
停下来
停止
别说了
别讲了
别念了
不要说了
别吵了
闭嘴
安静
安静点
打断
```

- 整句长度超过 12 个字符（归一化后）不判 stop。
- 反例（必须返回 `None`）：
  - 「我停不下来」
  - 「停在哪里」
  - 「别说了之后呢」
  - 「他叫我停下来」
  - 「安静的房间」
- 不要用「包含停字」这种宽规则；必须整句匹配。

### 5.3 `time`：询问时间

只有**整句**是下列短语之一（允许末尾 `了/啊/呀/呢/吗` 和标点）才返回 `kind="time"`：

```
现在几点
现在几点了
现在几点钟
几点了
几点
现在时间
现在是什么时间
什么时间
报时
```

- 反例：`你几点睡`、`现在三点`、`三点`、`我几点来` → `None`。
- 只解析意图，不读取系统时间。

### 5.4 `timer`：定时/提醒

必须同时满足：

1. 文本里出现计时关键词之一：`提醒`、`定时`、`计时`、`倒计时`、`闹钟`。
2. 能解析出一个「数字 + 时间单位」的时长。
3. 时长在 **1 秒到 86400 秒（24 小时）** 之间。

否则返回 `None`。

#### 数字

支持：

- 阿拉伯数字：`5`、`30`、`1.5`（允许一位小数）。
- 中文数字 1–99：`一`、`二`/`两`、`三`……`九`、`十`、`十一`、`二十`、`二十三`、`九十九`。
- `半`：`半小时` = 1800 秒，`半分钟` = 30 秒；`半秒` 不接受（太短）。
- `一个半小时` / `一个半钟头` = 5400 秒。
- `一刻钟` = 900 秒。

不要求支持「一百以上」「1小时30分」这类复合表达；遇到无法确定的情况返回 `None`，不要猜。

#### 单位

`秒`、`秒钟`、`分`、`分钟`、`小时`、`钟头`。

换算：

- 秒：原值
- 分/分钟：×60
- 小时/钟头：×3600

四舍五入到整数秒。

#### 否定/取消

以下情况返回 `None`：

- `别提醒`、`不要提醒`、`不用提醒`
- `别定时`、`不要定时`、`不用定时`
- `别计时`、`不要计时`
- `取消` + `提醒/定时/计时/闹钟`
- `关掉` + `闹钟/提醒/计时`
- `停止` + `计时/倒计时`

注意：`别忘了提醒我五分钟后喝水` 是有效提醒，不要因为出现「别」就误杀；只匹配上面的否定组合。

#### `label`

- 从原文中去掉：匹配到的时长片段、计时关键词、常见连接词（`后`、`以后`、`之后`、`叫我`、`提醒我`、`一下`、`的`、`定个`、`设个` 等）。
- 去掉首尾标点和空白，压缩连续空白。
- 截到 40 个字符。
- 可以为空字符串。

示例：

| 输入 | 结果 |
|---|---|
| `提醒我五分钟后喝水` | `timer`, seconds=300, label=`喝水` |
| `五分钟后提醒我喝水` | `timer`, seconds=300, label=`喝水` |
| `定个三分钟计时` | `timer`, seconds=180, label=`` |
| `半小时后叫我` | `timer`, seconds=1800, label=`` |
| `一小时后提醒我看锅` | `timer`, seconds=3600, label=`看锅` |
| `倒计时90秒` | `timer`, seconds=90, label=`` |
| `一个半小时后提醒我关火` | `timer`, seconds=5400, label=`关火` |
| `一刻钟后叫我` | `timer`, seconds=900, label=`` |
| `两分钟后提醒我关灯` | `timer`, seconds=120, label=`关灯` |
| `1.5小时后提醒我收衣服` | `timer`, seconds=5400, label=`收衣服` |
| `我三分钟后到` | `None`（没有计时关键词） |
| `提醒我` | `None`（没有时长） |
| `计时` | `None`（没有时长） |
| `定个0分钟` | `None`（小于 1 秒） |
| `计时999小时` | `None`（超过 24 小时） |
| `别提醒我五分钟后喝水` | `None` |
| `取消计时` | `None` |
| `关掉闹钟` | `None` |
| `别忘了提醒我五分钟后喝水` | `timer`, seconds=300, label=`喝水` |

### 5.5 返回对象

- `stop` / `time`：`seconds=None`，`label=""`，`raw=原文.strip()`。
- `timer`：`seconds=int`，`label` 按上面规则，`raw=原文.strip()`。
- `kind` 只能是 `"stop"`、`"time"`、`"timer"`。

## 6. 重要限制（写进模块 docstring）

当前 bridge 的 HTTP 契约是**请求/响应**：设备发起一轮，服务端才回音频。**回合外无法主动出声**。所以：

- C 可以把 `timer` 解析出来；
- 但集成层**不能**假装「到点会自动提醒」；
- 真要实现到点提醒，需要设备端增加长轮询/WebSocket，或本地蜂鸣器；
- C 模块本身不要起线程、不要 sleep、不要直接调用 TTS。

这个限制必须写进 `commands.py` 的 docstring，避免下一个 AI 误解。
